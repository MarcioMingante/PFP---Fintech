# FinTrack v0.1.0 — Release local

Data: 21/10/2026. Primeira entrega local versionada; sem GHCR ou deploy remoto.

## Escopo

Stack Docker Compose com Next.js, API .NET, PostgreSQL, Redis, RabbitMQ e
observabilidade local. Autenticação, contas, lançamentos de receita/despesa,
cartões, parcelamento, faturas, recorrências e dashboard disponíveis conforme
escopo documentado. Transferências, edição/exclusão de lançamentos e pagamentos
continuam pendentes; versão não declara encerramento de todas as fases anteriores.

## Validação direcionada

- Build Docker API/frontend e stack completa com imagens versionadas.
- Playwright: cadastro, conta, lançamentos, compra, parcelas e saldo esperado.
- Backup modo 600, catálogo válido e rejeição de destino existente.
- Restore em banco vazio; comparação de todo dump de dados SQL idêntica à origem.
- Outbox e filas drenadas antes de parar escritas.
- Migrations idempotentes e retorno às imagens `phase26` com schema compatível.
- Retomada de `v0.1.0` preservando dados e encerramento do ambiente descartável.

Suíte completa não executada: mudanças operacionais, escopo direcionado conforme
AGENTS.md. Nenhum ambiente pessoal foi atualizado; imagens locais preservadas.
